# Tipografías locales

El estudio visual comparó cinco familias descargadas del repositorio oficial
Google Fonts. La interfaz de producción usa únicamente **Covered By Your Grace**
para títulos y navegación, y **Waiting for the Sunrise** para texto, formularios
y jerarquías.

- Covered By Your Grace — SIL Open Font License 1.1 (`covered-by-your-grace/OFL.txt`)
- Waiting for the Sunrise — SIL Open Font License 1.1 (`waiting-for-the-sunrise/OFL.txt`)
- Reenie Beanie — SIL Open Font License 1.1 (`reenie-beanie/OFL.txt`)
- Just Another Hand — Apache License 2.0 (`just-another-hand/LICENSE.txt`)
- Rock Salt — Apache License 2.0 (`rock-salt/LICENSE.txt`)

Los archivos se sirven desde el propio proyecto; producción no depende de
Google Fonts ni de otra CDN.
