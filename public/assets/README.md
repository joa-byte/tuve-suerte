# Activos visuales

`paper-texture.svg`, `ink-underline.svg` y `select-mark.svg` fueron creados
específicamente para **Tuve suerte**. Son dibujos vectoriales originales del
proyecto y se distribuyen bajo los mismos términos que el repositorio.

La textura usa una semilla SVG fija (`seed="19"`): conserva las mismas fibras
entre renders, no provoca saltos de layout y pesa menos que una fotografía de
papel de resolución equivalente.

Las tipografías y sus licencias se documentan en `fonts/README.md`.
